# What Type of Basketball Player Are You?

This is a basketball personality quiz made with HTML, CSS, JavaScript, and Bootstrap. Answer five questions about how you play, and the quiz will show which basketball personality fits you best.

## Possible Results
- **The Leader:** Brings energy and encourages teammates.
- **The Shooter:** Enjoys scoring and taking big shots.
- **The Playmaker:** Creates opportunities and makes smart passes.
- **The Hard Worker:** Brings effort, defense, and hustle.

## How to Use
1. Open the website's `index.html` file in a browser.
2. Choose one answer for each of the five questions.
3. Select **Show My Result** to see your basketball personality.
4. Select **Take the Quiz Again** to start over.

## Files
- `index.html` contains the quiz questions and page structure.
- `css/style.css` contains the design and responsive styling.
- `js/script.js` handles the answers, scores, and results.
